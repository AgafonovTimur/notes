# Ноты / Notes / 音符

**Language / Язык / 语言:** [Русский](#русский) | [English](#english) | [中文](#中文)

## Русский

### Ноты

Приложение для заучивания и тренировки чтения нот, ладов (тональностей) и ритма.

Приложение состоит из трёх подразделов (вкладки вверху): **Ноты**, **Лады**, **Ритм**.

#### 1. Функционал приложения

**Раздел «Ноты»**
Работает так: на нотном стане отображается нота — надо выбрать какая это нота на клавиатуре под станом или на пк/миди клавиатуре. Правильный ответ = зелёный, неправильный — красный. Можно включить подсказку предыдущего ответа — понять, что выбрал неверно.
- Сложность — можно выбрать одну, 2 ноты или аккорд.
- Ключ — можно выбрать скрипичный, басовый или оба ключа.
- Разрешённые ноты — можно выбрать нужный набор нот для заучивания. 2 ноты — случайный выбор второй ноты. Для аккордов это выбор тоники.
- Добавочные линейки — можно выбрать от нуля до трёх.
- Обращения аккордов — работает для аккордов. Третье обращение появляется только если оно есть.
- Кнопки ответов — можно скрыть кнопки ответов под нотным станом (если отвечаешь на пк/миди клавиатуре).
- Миди клавиатура — можно подключить миди клавиатуру и отвечать на ней.
- Указывать октаву в ответе (от 2-й до 6-й) — под нотами появляется выбор октавы. Если галочка не поставлена — ответ правильной нотой в любой октаве засчитывается верным.
- Отображать клавиатуру — для удобства выбора нот.
- Рисовать ноты разной длительности — ноты отличаются только на вид.
- Цвета клавиатуры — можно поменять цвета клавиш.
- Выбор языка.
- Выбор темы (все темы на вид могут слегка отличаться в разных вкладках).
- Показывать ноту на стане в подсказке — если включена подсказка о прошлом вопросе, эта галочка добавляет эти ноты на стан рядом с вопросом — красным (если выбрано неверно), зелёным (если верно).
- Прозрачность цвета на клавишах — цвета правильного и неправильного ответа, которыми подсвечиваются клавиши нот.
- Цвета оформления — можно сменить на другие.
- Положение окна ошибок — можно подвинуть выше-ниже и правее-левее.
- Отображать настройки — перемещает окно влево-вправо или в центр экрана.

Показывает одну ноту (или несколько нот/аккорд) на нотном стане, нужно выбрать правильную.

**Раздел «Лады»**
Служит для заучивания ладов/тональностей. Отображается нота — надо достроить остальные ноты лада.
- Ключ — скрипичный, басовый или оба одновременно.
- Выбор ноты, от которой строить лад.
- Выбор, какие лады показывать в вопросах.
- Начинать со случайной ступени — надо построить лад не от первой ступени (внизу написана ступень и лад).
- Надпись названия лада — ползунки для изменения расположения и размера шрифта.
- Расположение и размер шрифта подсказки.
- Положение окна ошибок.
- Отображать настройки — перемещает окно влево-вправо или в центр экрана.
- Подключение миди клавиатуры.

**Раздел «Ритм»**
Состоит из двух режимов:

«Одна нота» — на экране показывается одна нота с определённой длительностью (например, четверть, восьмая), нужно нажать кнопку с правильным названием длительности.
- Можно выбрать, какие длительности отображать (целые, половинные, четверти, восьмые, шестнадцатые, с точкой и т.д.).
- Отвечать можно мышью, цифрами на клавиатуре или через MIDI-клавиатуру.

«Бесконечно» — ноты с ритмом непрерывно «едут» по экрану слева направо, нужно вовремя нажимать (тапать), попадая в ритм каждой ноты.
- Размер такта — можно выбрать 4/4, 3/4, 2/4, 6/8.
- Длительность ноты — можно выбрать несколько длительностей ноты.
- Скорость прокрутки — чем больше значение, тем быстрее едут ноты на экране.
- Метроном во время ритма — можно отключить, если мешает.
- Дробление метронома — можно включить метроном под другой такт (например, для 4/4 можно включить 1/8, и за каждую долю такта будет 2 удара, а не 1).
- Калибровка задержки — для точности звука метронома.

**Общее для всего приложения**
- Пять тем оформления.
- Поддержка трёх языков: русский, английский, китайский (упрощённый).
- Окно ошибок можно двигать по экрану и настраивать, с какой стороны появляется панель настроек.
- Поддержка мобильных устройств: открытие/закрытие меню — 2 нажатия одновременно, окно ошибок — 3 нажатия одновременно. Мобильную версию доделал не полностью — что-то работает, что-то нет. В целом версия рассчитана на ПК.

#### 2. Горячие клавиши (для компьютера)

| Клавиша | Действие |
|---|---|
| **W** (или **Ц**) / **Y** (или **Н**) / **Средняя кнопка мыши** | Открыть/закрыть панель настроек |
| **Q** (или **Й**) | Открыть/закрыть окно статистики ошибок |
| **+** / **-** | Увеличить/уменьшить масштаб нотного стана |
| **Shift + -** | Сбросить масштаб к значению по умолчанию (100%) |
| **A, B, C, D, E, F, G** | Ответить нотой (в разделах «Ноты» и «Лады»), работает и в русской раскладке ЙЦУКЕН |
| **Shift + буква ноты** | Ответить нотой с диезом (например, Shift+C = C#) |
| **Space, затем нота** | Ответить нотой с бемолем (например, Space затем D = Db) |
| **2–6** (после ноты, если включено указание октавы) | Указать номер октавы |
| **R** (или **К**) | Показать подсказку (название ноты), пока клавиша зажата |
| **T** (или **Е**) | Закрепить/открепить подсказку на экране |
| **Z** (или **Я**) | Показать на нотном стане подписи линеек, пока клавиша зажата |
| **1–9, 0** | В «Ритм → Одна нота»: быстрый ответ — цифра соответствует порядковому номеру кнопки длительности слева направо |
| **1–7** | В «Ритм → Одна нота»: быстрый ответ только для миди клавиатуры, от C до B любой октавы |
| **Пробел** | В «Ритм → Бесконечно»: тап (нажатие в ритм); также используется во время калибровки задержки звука |

#### 3. Что можно поменять через меню настроек (без изменения файла)

Панель настроек открывается клавишей **W** и содержит разные блоки в зависимости от выбранного раздела (Ноты / Лады / Ритм).

**Настройки раздела «Ноты»**
- Ключ: скрипичный, басовый или оба сразу.
- Сложность аккордов (простые / средние / сложные).
- Какие именно ноты разрешены (сеткой — можно включать/выключать каждую).
- Добавочные линейки (0, +1, +2, +3).
- Обращения аккордов (можно включить несколько).
- Показывать или скрывать кнопки ответов на клавиатуре под станом.
- Подключение MIDI-клавиатуры (выбор конкретного MIDI входа/выхода).
- Указывать ли октаву в ответе; показывать ли на экране клавиатуру пианино.
- Рисовать ли ноты разными длительностями (меняет только внешний вид).
- Цвета клавиш пианино (белые/чёрные).
- Язык интерфейса, тема оформления, показывать ли ноту на стане в подсказке, положение и размер подсказки.
- Цвет и прозрачность подсветки правильного/неправильного ответа на клавишах.
- Цвета оформления: фон страницы, цвет ключа, цвет линий стана, цвет фона стана.
- Положение окна статистики ошибок.
- С какой стороны экрана появляется панель настроек.

**Настройки раздела «Лады»**
- Ключ, тоники (с каких нот могут начинаться лады, можно несколько).
- Какие лады/тональности включены в тренировку.
- С какой ступени лада начинать.
- Язык, тема оформления.
- Положение и размер надписи с названием текущего лада.
- Цвет, положение и размер подсказки.
- Положение окна статистики ошибок.
- Сторона появления панели настроек.
- Подключение MIDI-клавиатуры.

**Настройки раздела «Ритм» → «Одна нота»**
- Какие длительности нот разрешены.
- Положение окна статистики ошибок.
- Язык, тема оформления, сторона появления панели настроек.
- Подключение MIDI-клавиатуры.

**Настройки раздела «Ритм» → «Бесконечно»**
- Размер такта (можно несколько одновременно).
- Какие длительности/элементы ритма могут встречаться.
- Скорость прокрутки нот по экрану (влияет только на картинку, не на сам ритм).
- Темп метронома (BPM) и его громкость; включение звука метронома во время игры; дробление метронома.
- Калибровка звуковой задержки (кнопка «Откалибровать»).
- Язык, тема оформления, сторона появления панели настроек.
- Подключение MIDI-клавиатуры.

**Окно статистики ошибок (открывается клавишей Q)**
- Для каждого раздела — своя статистика (по нотам отдельно для скрипичного/басового ключа, по ладам/ступеням, по длительностям).
- Кнопка «Очистить историю» для каждой статистики отдельно.
- Размер шрифта окна статистики.

#### 4. Что можно поменять только через правку самого файла (в коде)

Эти параметры не вынесены в меню настроек — чтобы их изменить, нужно открыть HTML-файл в текстовом редакторе и поправить значение вручную.

- Правило «не повторять одну и ту же ноту подряд»: максимальная глубина запрета повтора (сейчас — не более 3 последних нот подряд не повторяются).
- Список поддерживаемых аккордов и то, из каких нот они состоят.
- Список ладов/тональностей, доступных для выбора в разделе «Лады».
- Список длительностей нот, доступных в разделе «Ритм».
- Время ожидания цифры октавы после ввода буквы ноты (сейчас 3 секунды — если не успеть ввести октаву, ответ сбрасывается).
- Пределы движения окна статистики ошибок по горизонтали и вертикали.
- Чувствительность мобильных жестов: насколько можно сдвинуть пальцы и сколько времени должно пройти, чтобы касание всё ещё считалось «тапом», а не прокруткой.
- Внутренние размеры нотного стана (расстояние между линиями, положение ключа и т. п.).

## English

### Notes

An app for learning and practicing note reading, modes (keys), and rhythm.

The app has three sections (tabs at the top): **Notes**, **Modes**, **Rhythm**.

#### 1. App functionality

**"Notes" section**
Works like this: a note is shown on the staff — you need to pick which note it is, on the on-screen keyboard below the staff or on a PC/MIDI keyboard. Correct answer = green, wrong = red. You can enable a hint of your previous answer to see what you picked wrong.
- Difficulty — one note, 2 notes, or a chord.
- Clef — treble, bass, or both.
- Allowed notes — choose the set of notes to practice. For 2 notes, the second note is chosen at random. For chords, this selects the root.
- Ledger lines — choose from zero to three.
- Chord inversions — applies to chords; the third inversion only appears when it exists.
- Answer buttons — you can hide the answer buttons under the staff (if answering via PC/MIDI keyboard).
- MIDI keyboard — you can connect a MIDI keyboard and answer on it.
- Specify octave in the answer (2nd to 6th) — an octave selector appears below the notes. If unchecked, answering with the right note in any octave counts as correct.
- Show keyboard — for convenience when picking notes.
- Draw notes with different durations — purely visual, notes only differ in appearance.
- Keyboard colors — you can change the key colors if needed.
- Language selection.
- Theme selection (all themes may look slightly different across tabs).
- Show the note on the staff in the hint — if the previous-answer hint is enabled, this checkbox also adds those notes on the staff next to the question — red if picked wrong, green if picked right.
- Key highlight opacity — the colors used to highlight correct/incorrect note keys.
- Theme colors — can be changed.
- Error window position — can be moved up/down and left/right.
- Show settings — moves the panel left/right or centers it.

Shows one note (or several notes/a chord) on the staff; you need to pick the correct one.

**"Modes" section**
Used to learn modes/keys. A note is shown — you need to complete the rest of the mode's notes.
- Clef — treble, bass, or both at once.
- Choice of the note to build the mode from.
- Choice of which modes appear in the questions.
- Start from a random degree — build the mode not from the first degree (the degree and mode name are shown below).
- Mode-name label — sliders to change its position and font size.
- Position and font size of the hint.
- Error window position.
- Show settings — moves the panel left/right or centers it.
- MIDI keyboard connection.

**"Rhythm" section**
Has two modes:

"Single note" — a single note with a specific duration (e.g., quarter, eighth) is shown; you need to press the button with the correct duration name.
- You can choose which durations appear (whole, half, quarter, eighth, sixteenth, dotted, etc.).
- You can answer with the mouse, number keys, or a MIDI keyboard.

"Endless" — notes with a rhythm continuously scroll across the screen left to right; you need to tap in time with each note.
- Time signature — 4/4, 3/4, 2/4, 6/8.
- Note duration — you can select several note durations.
- Scroll speed — the higher the value, the faster the notes move.
- Metronome during play — can be turned off if it's distracting.
- Metronome subdivision — you can run the metronome on a different subdivision (e.g., for 4/4 you can enable 1/8 so there are 2 clicks per beat instead of 1).
- Latency calibration — for metronome sound accuracy.

**Common to the whole app**
- Five color themes.
- Support for three languages: Russian, English, Simplified Chinese.
- The error window can be moved around the screen, and you can set which side the settings panel appears on.
- Mobile support: open/close menu with 2 simultaneous taps, error window with 3 simultaneous taps. The mobile version isn't fully finished — some things work, some don't. Overall, the app is designed for PC.

#### 2. Keyboard shortcuts (for computer)

| Key | Action |
|---|---|
| **W** / **Y** / **Middle mouse button** | Open/close the settings panel |
| **Q** | Open/close the error-statistics window |
| **+** / **-** | Zoom the staff in/out |
| **Shift + -** | Reset zoom to default (100%) |
| **A, B, C, D, E, F, G** | Answer with a note (in "Notes" and "Modes"), also works on a Russian ЙЦУКЕН layout |
| **Shift + note letter** | Answer with a sharp note (e.g., Shift+C = C#) |
| **Space, then note** | Answer with a flat note (e.g., Space then D = Db) |
| **2–6** (after a note, if octave input is enabled) | Specify the octave number |
| **R** | Show the hint (note name) while held |
| **T** | Pin/unpin the hint on screen |
| **Z** | Show staff line labels while held |
| **1–9, 0** | In "Rhythm → Single note": quick answer — the digit matches the position of the duration button, left to right |
| **1–7** | In "Rhythm → Single note": quick answer for MIDI keyboard only, from C to B in any octave |
| **Space** | In "Rhythm → Endless": tap in time; also used during latency calibration |

#### 3. What you can change via the settings menu (without editing the file)

The settings panel opens with the **W** key and contains different blocks depending on the selected section (Notes / Modes / Rhythm).

**"Notes" section settings**
- Clef: treble, bass, or both at once.
- Chord difficulty (easy / medium / hard).
- Which notes are allowed (a grid — toggle each one).
- Ledger lines (0, +1, +2, +3).
- Chord inversions (several can be enabled).
- Show or hide the answer keyboard buttons under the staff.
- MIDI keyboard connection (choose a specific MIDI input/output).
- Whether to require an octave in the answer; whether to show the piano keyboard on screen.
- Whether to draw notes with different durations (visual only).
- Piano key colors (white/black).
- Interface language, theme, whether to show the note on the staff in the hint, hint position and size.
- Color and opacity of the correct/incorrect key highlight.
- Theme colors: page background, clef color, staff line color, staff background color.
- Error-statistics window position.
- Which side of the screen the settings panel appears on.

**"Modes" section settings**
- Clef, tonics (which notes modes can start from, several allowed).
- Which modes/keys are included in practice.
- Which degree to start the mode from.
- Language, theme.
- Position and size of the current mode-name label.
- Hint color, position, and size.
- Error-statistics window position.
- Side the settings panel appears on.
- MIDI keyboard connection.

**"Rhythm" → "Single note" settings**
- Which note durations are allowed.
- Error-statistics window position.
- Language, theme, side the settings panel appears on.
- MIDI keyboard connection.

**"Rhythm" → "Endless" settings**
- Time signature (several can be active at once).
- Which durations/rhythm elements can appear.
- Scroll speed of the notes on screen (affects visuals only, not the actual rhythm).
- Metronome tempo (BPM) and volume; metronome sound on/off during play; metronome subdivision.
- Sound-latency calibration ("Calibrate" button).
- Language, theme, side the settings panel appears on.
- MIDI keyboard connection.

**Error-statistics window (opened with Q)**
- Separate stats for each section (notes split by treble/bass clef, modes/degrees, durations).
- "Clear history" button for each stats set separately.
- Font size of the stats window.

#### 4. What can only be changed by editing the file itself (in code)

These settings aren't exposed in the settings menu — to change them, you need to open the HTML file in a text editor and edit the value manually.

- The "don't repeat the same note in a row" rule: maximum repeat-prevention depth (currently, no repeats among the last 3 notes).
- The list of supported chords and which notes make them up.
- The list of modes/keys available in the "Modes" section.
- The list of note durations available in the "Rhythm" section.
- The wait time for the octave digit after entering a note letter (currently 3 seconds — if you don't enter the octave in time, the answer resets).
- The movement limits of the error-statistics window, horizontally and vertically.
- Mobile gesture sensitivity: how far fingers can move and how much time can pass for a touch to still count as a "tap" rather than a scroll.
- Internal staff dimensions (spacing between lines, clef position, etc.).

## 中文

### 音符

一款用于学习和练习读谱、调式（调性）和节奏的应用。

应用包含三个部分（顶部标签页）：**音符**、**调式**、**节奏**。

#### 1. 应用功能

**"音符"部分**
运作方式：五线谱上显示一个音符——需要在谱表下方的键盘或电脑/MIDI 键盘上选出这是哪个音符。答对为绿色，答错为红色。可以开启上一题答案的提示，了解自己选错在哪里。
- 难度——可选单音、双音或和弦。
- 谱号——可选高音谱号、低音谱号或两者同时。
- 允许的音符——可选择要练习的音符范围。双音模式下，第二个音符随机选取；和弦模式下，这是选择根音。
- 加线——可选择 0 到 3 根。
- 和弦转位——适用于和弦，第三转位只在存在时才会出现。
- 答题按钮——可隐藏谱表下方的答题按钮（如果用电脑/MIDI 键盘作答）。
- MIDI 键盘——可连接 MIDI 键盘作答。
- 在答案中注明八度（2 至 6 度）——勾选后音符下方会出现八度选择；不勾选时，任意八度中答对音符即算正确。
- 显示键盘——方便选择音符。
- 绘制不同时值的音符——仅影响外观。
- 键盘颜色——可更改琴键颜色。
- 语言选择。
- 主题选择（各标签页下同一主题外观可能略有不同）。
- 在提示中显示谱表上的音符——若开启了上一题提示，此选项会在题目旁的谱表上也显示这些音符：选错为红色，选对为绿色。
- 琴键高亮透明度——正确/错误答案高亮琴键所用的颜色透明度。
- 主题配色——可更改。
- 错误窗口位置——可上下左右移动。
- 显示设置——将面板移到左/右或居中。

在五线谱上显示一个音符（或多个音符/和弦），需要选出正确答案。

**"调式"部分**
用于学习调式/调性。显示一个音符——需要补全该调式的其余音符。
- 谱号——高音谱号、低音谱号或两者同时。
- 选择作为调式起始的音符。
- 选择题目中出现哪些调式。
- 从随机级数开始——不从第一级开始构建调式（下方会标注级数和调式名称）。
- 调式名称标签——可用滑块调整位置和字号。
- 提示的位置和字号。
- 错误窗口位置。
- 显示设置——将面板移到左/右或居中。
- 连接 MIDI 键盘。

**"节奏"部分**
包含两种模式：

"单音符"——屏幕上显示一个具有特定时值的音符（例如四分音符、八分音符），需要按下对应时值名称的按钮。
- 可选择显示哪些时值（全音符、二分音符、四分音符、八分音符、十六分音符、附点音符等）。
- 可用鼠标、数字键或 MIDI 键盘作答。

"无限模式"——带节奏的音符从屏幕右侧持续向左滚动，需要在每个音符的节拍点及时点击（敲击）。
- 拍号——可选 4/4、3/4、2/4、6/8。
- 音符时值——可选择多种时值。
- 滚动速度——数值越大，音符移动越快。
- 节奏进行中的节拍器——如果干扰可以关闭。
- 节拍器细分——可以让节拍器以不同的细分演奏（例如 4/4 拍下开启 1/8 细分，每一拍会有 2 次敲击而不是 1 次）。
- 延迟校准——用于校正节拍器声音的准确性。

**整个应用的通用功能**
- 五种配色主题。
- 支持三种语言：俄语、英语、简体中文。
- 错误窗口可在屏幕上移动，并可设置设置面板出现的方向。
- 移动设备支持：打开/关闭菜单需同时点击两下，错误窗口需同时点击三下。移动端版本尚未完全适配——部分功能可用，部分不可用。整体上该版本主要面向电脑设计。

#### 2. 快捷键（电脑端）

| 按键 | 操作 |
|---|---|
| **W** / **Y** / **鼠标中键** | 打开/关闭设置面板 |
| **Q** | 打开/关闭错误统计窗口 |
| **+** / **-** | 放大/缩小五线谱 |
| **Shift + -** | 将缩放重置为默认值（100%） |
| **A, B, C, D, E, F, G** | 用音符作答（"音符"和"调式"部分），在俄语 ЙЦУКЕН 键盘布局下同样有效 |
| **Shift + 音符字母** | 用升号音符作答（例如 Shift+C = C#） |
| **空格，然后音符** | 用降号音符作答（例如空格后按 D = Db） |
| **2–6**（在音符之后，若开启了八度输入） | 指定八度编号 |
| **R** | 按住时显示提示（音符名称） |
| **T** | 在屏幕上固定/取消固定提示 |
| **Z** | 按住时在五线谱上显示线条标注 |
| **1–9, 0** | 在"节奏 → 单音符"中：快速作答——数字对应从左到右时值按钮的顺序编号 |
| **1–7** | 在"节奏 → 单音符"中：仅限 MIDI 键盘的快速作答，从任意八度的 C 到 B |
| **空格** | 在"节奏 → 无限模式"中：按节拍点击；也用于声音延迟校准过程中 |

#### 3. 通过设置菜单可更改的内容（无需修改文件）

按 **W** 键打开设置面板，其内容会根据当前所选部分（音符 / 调式 / 节奏）而不同。

**"音符"部分设置**
- 谱号：高音谱号、低音谱号或两者同时。
- 和弦难度（简单 / 中等 / 困难）。
- 具体允许哪些音符（以网格形式逐个开关）。
- 加线（0、+1、+2、+3）。
- 和弦转位（可开启多个）。
- 显示或隐藏谱表下方的答题按钮。
- 连接 MIDI 键盘（选择具体的 MIDI 输入/输出）。
- 答案中是否需要指定八度；是否在屏幕上显示钢琴键盘。
- 是否绘制不同时值的音符（仅影响外观）。
- 钢琴键颜色（白键/黑键）。
- 界面语言、主题、提示中是否显示谱表上的音符、提示的位置和大小。
- 琴键上正确/错误答案高亮的颜色和透明度。
- 主题配色：页面背景、谱号颜色、谱线颜色、谱表背景颜色。
- 错误统计窗口位置。
- 设置面板出现在屏幕的哪一侧。

**"调式"部分设置**
- 谱号、主音（调式可从哪些音符开始，可多选）。
- 练习中包含哪些调式/调性。
- 从哪个级数开始。
- 语言、主题。
- 当前调式名称标签的位置和大小。
- 提示的颜色、位置和大小。
- 错误统计窗口位置。
- 设置面板出现的一侧。
- 连接 MIDI 键盘。

**"节奏" → "单音符"设置**
- 允许哪些音符时值。
- 错误统计窗口位置。
- 语言、主题、设置面板出现的一侧。
- 连接 MIDI 键盘。

**"节奏" → "无限模式"设置**
- 拍号（可同时启用多个）。
- 可出现哪些时值/节奏元素。
- 音符在屏幕上滚动的速度（仅影响画面，不影响实际节奏）。
- 节拍器速度（BPM）及音量；演奏过程中是否开启节拍器声音；节拍器细分。
- 声音延迟校准（"校准"按钮）。
- 语言、主题、设置面板出现的一侧。
- 连接 MIDI 键盘。

**错误统计窗口（按 Q 打开）**
- 每个部分都有各自的统计数据（音符按高音/低音谱号分别统计，调式按级数统计，节奏按时值统计）。
- 每种统计各自都有独立的"清除历史"按钮。
- 统计窗口的字号大小。

#### 4. 只能通过修改文件本身更改的内容（代码）

这些设置未在设置菜单中开放——若要更改，需要用文本编辑器打开 HTML 文件并手动修改数值。

- "不连续重复同一音符"规则：禁止重复的最大深度（目前为最近 3 个音符内不重复）。
- 支持的和弦列表及其组成音符。
- "调式"部分可供选择的调式/调性列表。
- "节奏"部分可用的音符时值列表。
- 输入音符字母后等待八度数字的时间（目前为 3 秒——若未及时输入八度，答案会被重置）。
- 错误统计窗口水平和垂直方向的移动范围限制。
- 移动端手势灵敏度：手指可移动的距离范围及需经过多长时间，触摸才仍被视为"点击"而非滑动。
- 五线谱内部尺寸（线间距、谱号位置等）。
