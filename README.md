# Note Trainer (тренажёр нот)

Одностраничное HTML-приложение (без сборки, без зависимостей) для тренировки чтения нот на нотном стане: отдельные ноты, интервалы, аккорды, а также тональности и лады.

Открывается просто запуском `.html` файла в браузере.

---

## 1. Функционал приложения

### Уровень «Ноты»

- **Режимы сложности** (переключаются в меню, раздел «Сложность»):
  - 1 нота
  - 2 ноты (интервал)
  - Простые аккорды: maj, min
  - Средние аккорды: maj7, 7, min7, sus2, sus4
  - Сложные аккорды: dim, aug, 6, min6, add9, m7♭5 (полууменьшённый)
- **Ключи**: скрипичный, басовый, либо оба одновременно (большой стан).
- **Разрешённые ноты**: можно включать/выключать любую из 17 нотных «фишек» (7 натуральных, 5 диезов, 5 бемолей); вероятность появления каждой включённой ноты равна 1/N, где N — число включённых.
- **Добавочные линейки**: диапазон расширения нотного стана вверх/вниз (0, +1, +2, +3).
- **Названия нот**: буквенные (A B C…) или сольфеджио (До Ре Ми…).
- **Обращения аккордов**: можно включить 1-е, 2-е, 3-е и 4-е обращение (по отдельности или в любой комбинации) — аккорд тогда рисуется/задаётся не в основном виде.
- **Кнопки ответов**: можно показать экранные кнопки-ноты для ответа мышью/тапом или скрыть их (тогда ответ только с клавиатуры/MIDI/пианино).
- **MIDI-клавиатура**: подключение реального MIDI-инструмента через Web MIDI; нажатия клавиш засчитываются как ответ.
- **Точность ответа**:
  - режим с указанием октавы (ответ надо давать вместе с октавой, C2–C6);
  - отображение экранной клавиатуры пианино (C2–C6) для ответа кликом.
- **Подсказка (Reveal)**: по удержанию клавиши показывает правильный ответ на стане/клавиатуре; можно закрепить подсказку, чтобы она не пропадала. Настраиваются положение, размер и то, показывать ли саму нотную головку на стане в подсказке.
- **Индикация верно/неверно**: подсвечивает нажатую клавишу/клавишу пианино цветом (зелёный/красный), с настраиваемой прозрачностью и цветом каждого состояния.
- **Статистика ошибок**: отдельная панель «Ошибки» ведёт учёт неверных ответов по нотам, отдельно для скрипичного и басового ключа, с настраиваемым размером шрифта таблицы; историю можно очистить.
- **Подсказка линий стана**: по удержанию клавиши Z показываются подписи линий и промежутков нотного стана (какая линия — какая нота).
- **Полноэкранный режим и масштабирование**: интерфейс подстраивается под F11-фуллскрин; масштаб всего приложения можно менять на лету.
- Все настройки и статистика сохраняются в `localStorage` браузера и восстанавливаются при перезапуске.

### Уровень «Тональности / Лады»

- Отдельная вкладка в меню, использует тот же нотный стан, ключи и клавиатуру пианино, что и уровень «Ноты».
- **9 типов лада/гаммы**: мажор, натуральный минор, гармонический минор, мелодический минор, дорийский, фригийский, лидийский, миксолидийский, локрийский.
- **Тоники**: можно включить любое количество тоник, из которых будет случайно выбираться текущее задание.
- **Ступень начала**: по умолчанию гамма всегда начинается с тоники; можно включить случайное начало с любой ступени лада.
- Ноты гаммы показываются на стане последовательно слева направо, ответ даётся по одной ноте за раз (буквой, пианино или MIDI).
- Первая (заданная) нота тоники подсвечивается отдельным цветом-«маячком» и не перекрашивается при вводе.
- **Подсказка названия лада** (например, «D dorian») — положение и размер надписи настраиваются.
- **Подсказка ноты** (R/К, закрепление T/е) — отдельные настройки положения и размера именно для режима ладов.
- Статистика ошибок по ладам/ступеням — в той же панели «Ошибки», с отдельной вкладкой.

### Общее

- Все настройки цвета (фон, ключ, линии стана, фон стана, клавиши пианино, цвета верного/неверного ответа) можно менять из меню без правки кода.
- Приложение — полностью автономный `.html`-файл: никаких серверов, сборки или интернет-зависимостей (кроме, при желании, реального MIDI-устройства).

## 2. Горячие клавиши

| Клавиша | Действие |
|---|---|
| `A B C D E F G` (лат.) или `Ф И С В У А П` (рус., та же физическая клавиша в раскладке ЙЦУКЕН) | Ответ соответствующей нотой |
| `Shift` + буква ноты | Ответ с диезом/бемолем (в зависимости от того, какая альтерация назначена клавише) |
| `2`–`6` | Указать октаву ответа (если включён режим «Указывать октаву»), вводится сразу после буквы ноты |
| `R` / `К` (удержание) | Показать подсказку (правильный ответ) |
| `T` / `Е` | Закрепить/открепить подсказку (чтобы не нужно было удерживать `R`) |
| `Z` (удержание) | Показать подписи линий и промежутков нотного стана |
| `W` / `Ц` | Открыть/закрыть панель настроек |
| `Q` / `Й` | Открыть/закрыть панель статистики ошибок |
| `+` / `=` | Увеличить масштаб интерфейса |
| `-` / `_` | Уменьшить масштаб интерфейса |
| `Shift` + `-` | Сбросить масштаб на 100% |

На уровне «Тональности / Лады» используются те же буквенные клавиши и те же клавиши `R/К`, `T/Е` — ответ идёт по текущей ступени гаммы, а не в общий обработчик режима «Ноты».

## 3. Что можно поменять через меню (без правки кода)

Открывается клавишей `W`/`Ц` или кнопкой меню; переключение между уровнями «Ноты» и «Тональности / Лады» — вкладками сверху.

**Уровень «Ноты»:**
- Сложность (1 нота / 2 ноты / аккорды трёх уровней сложности)
- Ключ (скрипичный / басовый / оба одновременно)
- Разрешённые ноты (любая комбинация из 17 нот, включая энгармонические варианты)
- Диапазон добавочных линеек (0…+3)
- Формат названий нот (буквы / сольфеджио)
- Обращения аккордов (любая комбинация 1–4)
- Показывать или скрывать экранные кнопки ответа
- Подключение MIDI-клавиатуры
- Указывать ли октаву в ответе
- Показывать ли экранную клавиатуру пианино
- Цвета белых/чёрных клавиш пианино
- Показывать ли нотную головку в подсказке; положение и размер подсказки
- Цвет и прозрачность подсветки верного/неверного ответа
- Цвета оформления: фон, ключ, линии стана, фон стана

**Уровень «Тональности / Лады»:**
- Ключ (скрипичный / басовый / оба одновременно)
- Тоники (любая комбинация)
- Типы ладов/гамм (любая комбинация из 9)
- Случайная ступень начала гаммы (вкл/выкл)
- Положение и размер надписи названия лада
- Положение и размер подсказки ноты

**Панель «Ошибки» (`Q`/`Й`):**
- Просмотр статистики ошибок отдельно для нот и для ладов
- Размер шрифта таблицы ошибок
- Очистка истории ошибок

## 4. Что можно поменять только через настройки внутри файла

Все параметры вынесены в именованные CSS-переменные (`:root` в начале `<style>`) и именованные JS-константы — «магических чисел» в коде нет.

# Настройки (`:root` CSS-переменные)

## Цветовая схема и внешний вид

- `--bg` — основной фон приложения
- `--panel-bg` — фон панелей (настройки, ошибки)
- `--staff-bg` — фон нотного стана
- `--panel-border` — цвет рамок панелей

## Кнопки

- `--btn-bg` — основной цвет кнопок
- `--btn-bg-bottom` — нижняя тень кнопок (эффект объёма)
- `--btn-text` — цвет текста кнопок
- `--btn-hover` — цвет кнопки при наведении
- `--btn-shadow-depth` — глубина тени кнопок (эффект «нажатия»)

## Ноты и нотный стан

- `--accent` — основной акцентный цвет приложения
- `--note-fill` — цвет заливки нотных головок
- `--note-stroke` — цвет обводки нотных головок
- `--clef-color` — цвет музыкального ключа
- `--line-color` — цвет линий нотного стана

## Цвета правильного / неправильного ответа

- `--correct-color` — цвет правильного ответа
- `--correct-opacity` — прозрачность правильного ответа
- `--wrong-color` — цвет неправильного ответа
- `--wrong-opacity` — прозрачность неправильного ответа

## Клавиатура пианино

- `--piano-white-key` — цвет белых клавиш
- `--piano-black-key` — цвет чёрных клавиш

## Текст

- `--text-main` — основной цвет текста
- `--text-dim` — приглушённый цвет текста

## Скругления

- `--radius` — радиус больших элементов
- `--radius-sm` — радиус маленьких элементов

## Шрифты

- `--font-display` — декоративный шрифт (используется для отображения нот/подсказок)
- `--font-ui` — основной шрифт интерфейса

## Панель настроек

- `--settings-width` — ширина панели настроек
- `--settings-block-gap` — вертикальный отступ между блоками настроек

## Подсказка режима «Ноты»

- `--chord-reveal-top` — положение сверху
- `--chord-reveal-left` — положение слева
- `--chord-reveal-size` — размер текста подсказки

## Название лада

- `--scale-label-top` — положение сверху
- `--scale-label-left` — положение слева
- `--scale-label-size` — размер текста

## Подсказка режима «Лады»

- `--scale-hint-top` — положение сверху
- `--scale-hint-left` — положение слева
- `--scale-hint-size` — размер текста

## История ошибок

- `--error-font-size` — размер шрифта таблицы ошибок
- `--err-width` — ширина окна истории ошибок
- `--err-height` — максимальная высота окна истории ошибок

## Положение окон

Положение задаётся относительно **центра экрана**.

- `--errors-offset-x` — смещение окна ошибок по горизонтали
- `--errors-offset-y` — смещение окна ошибок по вертикали
- `--settings-offset-x` — смещение панели настроек по горизонтали
- `--settings-offset-y` — смещение панели настроек по вертикали

## Масштаб приложения

- `--app-scale` — общий масштаб интерфейса

## Размеры нотного стана

- `--staff-width` — базовая ширина нотного стана

## Отступы фона нотного стана

Позволяют изменить размеры тёмного блока вокруг стана без изменения размеров самого SVG.

- `--staff-box-pad-top` — верхний внутренний отступ
- `--staff-box-pad-bottom` — нижний внутренний отступ
- `--staff-box-pad-left` — левый внутренний отступ
- `--staff-box-pad-right` — правый внутренний отступ

**Логика и данные** (JS-константы в `<script>`):
- `LS_SETTINGS`, `LS_ERRORS`, `LS_STATS` и аналогичные ключи для ладов — имена ключей `localStorage`, под которыми хранятся настройки/статистика
- `NATURAL_LETTERS` — список натуральных нот
- `SOLFEGE` — соответствие букв нот слоговым названиям (До/Ре/Ми…)
- `BASE_SEMITONE` — базовая высота (в полутонах) для каждой буквы ноты
- `RU_TO_LETTER` — соответствие русских клавиш клавиатуры буквам нот (раскладка ЙЦУКЕН)
- `TOKENS` — список всех 17 «нотных фишек» (натуральные/диезы/бемоли) и их подписи
- `CHORD_DEFS` — определения всех типов аккордов (`simple`/`medium`/`complex`): состав по ступеням и в полутонах
- `SCALE_TYPES` — определения всех 9 типов ладов (интервальная формула, названия)
- `REVEAL_AUTO` — параметры автоматического позиционирования подсказки
- `ERR_BASE_COLS` — заголовки столбцов таблицы ошибок
- `STAFF_BASE_Y`, `STEP_PX`, `NOTE_X`, `SECOND_OFFSET` — геометрия нотного стана (базовая высота линии, шаг между ступенями в пикселях, X-координата центра нот, смещение для секунд/кластеров нот)
- `REFERENCE_VIEWBOX_WIDTH`, `BASE_STAFF_WIDTH`, `SINGLE_STAFF_CENTER_Y` — базовые размеры для пересчёта масштаба и центрирования одиночного стана
- `BLACK_KEY_SLOTS` — раскладка чёрных клавиш экранного пианино
- `PENDING_OCTAVE_TIMEOUT_MS` — сколько миллисекунд приложение ждёт цифру октавы после буквы ноты, прежде чем сбросить ввод
- `BODY_EDGE_GAP` — отступ от края страницы, учитываемый при расчётах скролла/позиционирования

Изменение любого из этих значений не требует правки логики — все использующие их места в коде ссылаются на константу/переменную, а не на захардкоженное число.
